# Severed Cursor Prompt Pack - how to use it with Claude and Cursor Pro

This pack contains **27 sequential Cursor Agent prompts** (plus control files) that take *Severed: Trials of Olympus* from an empty folder to a tested, packaged local 1v1 MVP. It was written from your revised GDD and Build Requirements. Where those documents disagree with the revised MVP scope, the MVP scope wins; every resolution is recorded in `DECISIONS.md`.

## What the MVP is (locked)
Godot 4 - local 1v1 - 4 fighters (Theron, Atalanta, Pyrrhus, Sibyl) - 3 arenas (Mount Olympus, Athens Colosseum, Tartarus Pits) - 21 data-driven abilities - 5 regrown limbs - fighters/arenas/limbs generated by Blender Python scripts on one shared skeleton with sockets - deterministic fixed-tick integer combat sim - code-driven animation - generated placeholder audio - Career/Fresh Body/Versus/Practice modes - local saves - Windows and Linux export. Online rollback, ranked, 4-player, co-op, spectator, Death Match/Thunder Strike/Legacy and the rest of the roster are **deferred**.

## Setup (once)
1. Do the *Pre-flight* in `MANUAL_CHECKPOINTS.md` (install tools, create project folder, copy this whole folder into the project root, allow terminal commands for the Agent).
2. Open the project folder in Cursor.

## Running a stage
1. Open a **new Cursor Agent chat** (Agent mode, a strong coding model, auto-run for allow-listed commands).
2. Attach/paste the next prompt file from `PROMPT_INDEX.md` (start with `00_README_AND_EXECUTION_GUIDE.md`). Tip: in Cursor you can type `@` and select the file, then write: *"Execute this prompt file exactly."*
3. Let Cursor work. It inspects, plans, implements, runs checks, fixes failures, updates `PROJECT_STATUS.md` and writes a handoff report with the **exact next filename**.
4. If the stage says COMPLETE and no checkpoint is due, start the next prompt in a fresh chat. If a checkpoint is due (after 05, 13, 20, 23, 24), do it from `MANUAL_CHECKPOINTS.md` first.
5. If anything is interrupted or you are lost, paste `RESUME_PROMPT.md`.

## Honest expectations
- Prompts reduce rework but cannot guarantee Cursor will get everything right first time. The workflow (tests, golden replays, validators, status tracker) exists to catch errors early.
- Code-generated low-poly art will be cohesive and consistent, not professional hand-made quality. Checkpoint B and C are where you judge and ask for improvements.
- Automated tests prove rules and consistency; they do **not** prove fun, balance feel, visual quality or performance on other machines.
- Platform policies (Steam, itch.io), licences and copyright for AI-assisted content change; stage 22B makes Cursor record what it verified versus assumed. It is not legal advice.
- Cursor Pro has usage limits; later stages are long. Using one chat per stage keeps context small. Work can pause safely at any stage boundary.
- I could not run Godot, Blender or Cursor while writing this pack, so no prompt has been executed. The prompts tell Cursor to verify every version and command rather than trust assumptions (including the tool names/flags mentioned here).

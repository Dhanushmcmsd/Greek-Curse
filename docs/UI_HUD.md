# Combat HUD and flow

Health bars include delayed ghost damage. Thin blue/gold bars show stamina/ultimate, with explicit numeric labels. Body diagrams show head/torso main zones and four limb values: H/solid, B/hatch, !/dots, X/outline. The patterns are generated by tools/ui/generate_patterns.gd. Combo eligibility, credit and Fury use simulation data/events. No color-only status.

RoundFlow pauses simulation stepping through intro, ready, round end and results. Escape/gamepad Start pauses; Resume/Restart/Controls/Quit to temporary mode launcher are focusable buttons. Results show rounds, damage, longest combo and amputation records; no progression yet.

SettingsHooks scales camera shake and cosmetic pose freeze; it does not change the deterministic combat hit-stop clock. Flash reduction suppresses sparks/edge warnings; gore Off suppresses sever particles and flying chunks. Blood color is selectable through hooks. UI scale applies theme font size; full settings UI remains stage 16.

Visual QA fixed resource-bar minimum-height overlap, narrowed debug panel and widened the combat-camera view of fighters (50-degree FOV). Preserved imported skeleton rest rotations after an observed upside-down limb failure.
